# vBook VS Code Tester Extension

Plugin kiểm thử extension vBook trực tiếp trên Visual Studio Code (phiên bản `0.0.5`).

## Tính năng
- Kết nối tới vBook Developer Server trên điện thoại qua Wi-Fi / Local Network.
- Chạy thử nhanh từng script (`home.js`, `detail.js`, `toc.js`, `chap.js`) và xem log trực tiếp trên panel Output của VS Code.
- Cài đặt nhanh extension lên app chỉ bằng một phím tắt.

## Cài đặt
1. Mở VS Code, nhấn tổ hợp phím `Ctrl + Shift + P` (hoặc `Cmd + Shift + P` trên macOS).
2. Nhập `Extensions: Install from VSIX...`.
3. Chọn file `tools/vscode/vbook-vscode-tester-0.0.5.vsix`.
4. Cấu hình IP và Port của vBook Developer Server trong Settings.
